# Dokumentation – Umsetzung F-007

> Die Sprache wird beim ersten Besuch aus der Browsersprache gewählt; eine Wahl im Header gilt danach und wird gespeichert.

*Annahme: Die Entwürfe für Französisch und Italienisch sind brauchbar, aber ungeprüft (Q-007-12).*

**Künftiges Problem: Fehlermeldungen vom Server (z. B. aus F-001 auf Deutsch, aus F-002 auf Englisch) erscheinen in der Serversprache, nicht in der gewählten Oberflächensprache. Solange der Server keine Schlüssel liefert, bleibt das so.**

**Künftiges Problem: Die Kategorie-Labels (Affirmative, Reproductive, …) bleiben in allen Sprachen englisch, wie in F-009 festgelegt. Die Erklärungen sind übersetzt. Ob die Labels übersetzt werden sollen, entscheidet der Nutzer.**
