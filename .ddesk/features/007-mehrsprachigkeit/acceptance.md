- **AC-007-1** Gegeben ein Besucher, dessen Browser Französisch, Italienisch oder Deutsch meldet (z. B. `fr-CH`) / Wenn er die Seite zum ersten Mal öffnet / Dann ist die Oberfläche in dieser Sprache.
- **AC-007-2** Gegeben ein Besucher / Wenn er im Header eine andere Sprache wählt / Dann wechselt die Oberfläche sofort, ohne Neuladen, und die Seite bleibt dieselbe.
- **AC-007-3** Gegeben eine gespeicherte Sprachwahl / Wenn der Browser später eine andere Sprache meldet oder der Besucher die Seite erneut öffnet / Dann gilt weiter die gespeicherte Wahl.
- **AC-007-4** Gegeben eine der vier Sprachen / Wenn der Besucher Anmeldung, Registrierung, Dateien, Benutzerverwaltung und die Ideen-Seiten öffnet / Dann sind alle Texte, Labels, Platzhalter und Hinweise des Frontends in dieser Sprache, ohne englische Reste.
- **AC-007-5** Gegeben eine Browsersprache, die nicht zu Deutsch, Englisch, Französisch oder Italienisch gehört (z. B. Spanisch) / Wenn der Besucher die Seite zum ersten Mal öffnet / Dann ist die Oberfläche auf Englisch.
