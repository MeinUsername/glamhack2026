- **AC-009-1** Gegeben das Erfassungsformular der Seite / Wenn der Nutzer keine, eine oder mehrere der vier Kategorien wählt und speichert / Dann wird die Seite gespeichert.
- **AC-009-2** Gegeben das Feld Kategorien / Wenn ein Wert außerhalb der vier Kategorien übermittelt wird / Dann wird der Wert abgelehnt.
- **AC-009-3** Gegeben das Feld Kategorien / Wenn dieselbe Kategorie zweimal übermittelt wird / Dann wird sie nur einmal gespeichert.
- **AC-009-4** Gegeben der Feldtitel mit Tooltip / Wenn der Nutzer den Tooltip öffnet / Dann erscheinen der Tooltip-Kopf, die Erklärung zu jeder der vier Kategorien und die Quellenangabe.
- **AC-009-5** Gegeben eine gespeicherte Seite mit gewählten Kategorien / Wenn die Seite abgerufen oder angezeigt wird / Dann erscheinen die gewählten Kategorien als Chips unter dem Seitentitel.
- **AC-009-6** Gegeben eine gespeicherte Seite ohne Kategorie / Wenn die Seite angezeigt wird / Dann erscheint kein Chip-Block.
