# F-020 Akzeptanzkriterien

- **AC-020-1** Gegeben die Seite einer Idee / Wenn sie geladen wird / Dann ist ein deutlich sichtbarer Bearbeiten-Button vorhanden, der zu `/ideas/{id}/edit` führt.
- **AC-020-2** Gegeben die Übersichtsseite / Wenn eine Idee angezeigt wird / Dann führt ein Bearbeiten-Einstieg direkt zum Formular dieser Idee.
- **AC-020-3** Gegeben das Bearbeiten-Formular / Wenn es geöffnet wird / Dann sind alle Felder und die vorhandenen Bilder der Idee vorbelegt.
- **AC-020-4** Gegeben das Bearbeiten-Formular / Wenn ein Nutzer ein Bild entfernt, ein neues hinzufügt und speichert / Dann zeigt die Idee-Seite genau die verbleibenden und die neuen Bilder.
- **AC-020-5** Gegeben eine Idee mit 5 Bildern / Wenn ein Nutzer ein sechstes hinzufügen will / Dann wird das mit einer verständlichen Meldung abgelehnt.
- **AC-020-6** Gegeben ein nicht eingeloggter Besucher / Wenn er eine Idee bearbeitet und speichert / Dann wird die Änderung gespeichert und er sieht die geänderte Idee.
