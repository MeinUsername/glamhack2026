# F-026 Akzeptanzkriterien

- **AC-026-1** Gegeben die Detailseite einer Idee mit Concept / Wenn sie geladen wird / Dann ist «Mediation Concept» der letzte Abschnitt, nach «Budget», und alle übrigen Abschnitte behalten ihre bisherige Reihenfolge.
- **AC-026-2** Gegeben eine Idee ohne Concept / Wenn die Detailseite geladen wird / Dann ist kein Concept-Abschnitt sichtbar (unverändert zu AC-023-6).
- **AC-026-3** Gegeben das Formular zum Anlegen oder Bearbeiten einer Idee / Wenn es geöffnet wird / Dann ist das Concept-Feld das letzte Eingabefeld, direkt vor den Aktionen.
- **AC-026-4** Gegeben ein Concept / Wenn es gespeichert und neu geladen wird oder der Master-Prompt erzeugt wird / Dann sind Inhalt, Rendering und Prompt-Ausgabe unverändert zu F-023.
